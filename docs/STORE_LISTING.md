## 2. 详细说明（中文）

Manekilex 帮助中文读者读英文。在网页、PDF 或内置 EPUB 阅读器里选中一个英文单词、短语或句子，点击旁边的招财猫小球，就能看到中文解释。

- 词典优先：单词和短语先查随扩展附带的本地词典，立即显示基础释义。
- AI 补充（可选）：填入你自己的 OpenAI、DeepSeek、Moonshot、智谱、SiliconFlow、Groq 或 Google Gemini API Key 后，扩展会把选中的文字和所在句子发给你选择的服务商，补充此处含义、原句翻译、派生词、同义词和助记。句子和段落直接由模型解释。
- 生词本：查过的词连同句子保存在本机，按间隔重复安排复习，可导出 TXT、CSV、Markdown。
- 阅读：内置 EPUB 阅读器，支持书签、目录和阅读进度；TXT、Markdown、HTML、DOCX、PDF 可在本机转成 EPUB。Chrome 151 及以上可以用增强 PDF 阅读器打开网页上的 PDF 并直接划词，也可以随时切回 Chrome 自带查看器。
- 实时转译（可选）：用你自己的 AssemblyAI Key，把麦克风或标签页的英文语音转成字幕，再由所选模型翻译。

扩展没有自己的服务器，不收集统计数据。不配置任何 Key 时，只使用本地词典。本地词典的大部分例句、语境说明和助记由 AI 生成，可能有错误。

## 3. Detailed description (English)

Manekilex helps Chinese-speaking readers read English. Select an English word, phrase or sentence on a web page, in a PDF or in the built-in EPUB reader, click the lucky-cat bubble next to it, and get an explanation in Chinese.

- Dictionary first: words and phrases are looked up in a dictionary that ships with the extension, and the basic meaning appears at once.
- Optional AI: with your own API key for OpenAI, DeepSeek, Moonshot, Zhipu, SiliconFlow, Groq or Google Gemini, the extension sends the selected text and its sentence to the provider you chose, to add the meaning in context, a translation of the sentence, related words, synonyms and a memory tip. Sentences and paragraphs are explained by the model.
- Vocabulary: looked-up words are saved with their sentence on your device, scheduled for spaced review, and can be exported as TXT, CSV or Markdown.
- Reading: a built-in EPUB reader with bookmarks, table of contents and reading position; TXT, Markdown, HTML, DOCX and PDF can be converted to EPUB on your device. On Chrome 151 and later, web PDFs can open in an enhanced PDF reader where you can select words directly, with a button to return to Chrome's own viewer.
- Optional live transcription: with your own AssemblyAI key, English speech from the microphone or a tab becomes captions, translated by the model you chose.

The extension has no server of its own and collects no analytics. Without any key it uses the local dictionary only. Most example sentences, context notes and memory tips in the local dictionary were generated by AI and may contain mistakes.

## 4. 单一用途说明（隐私标签页 Single purpose）

> 帮助用户理解所读英文：在网页、PDF 和 EPUB 中选中英文后显示中文解释，并把查过的词保存为生词本供复习。
>
> Help the user understand the English they are reading: show a Chinese explanation of selected English text on web pages, PDFs and EPUBs, and keep looked-up words in a vocabulary list for review.

阅读器、PDF 处理和实时转译都服务于「读懂英文」这一用途。实时转译把英文语音变成可查词的字幕；如果审核认为它超出单一用途，可考虑把它拆成独立扩展（需维护者决定）。

## 5. 权限说明（每项权限的 justification 字段）

| 权限 | 说明（可直接填写，英文供审核） |
| --- | --- |
| Host access via content scripts `<all_urls>`, `all_frames` | The lookup bubble must work on any page the user reads, including text inside iframes (e.g. embedded articles, online documents). The content script only reacts to the user's own text selection and sends nothing off the device until the user clicks the bubble. |
| `storage` | Saves the user's settings, API keys, vocabulary, review schedule and lookup cache on the device. |
| `unlimitedStorage` | Imported EPUB books (up to 100 MB each) and the vocabulary are stored locally in IndexedDB and chrome.storage; the default quota is too small. |
| `tabs` | Reads the current tab's URL to recognise PDF tabs (to offer the PDF reader and context-menu lookup), finds an already open settings tab instead of opening duplicates, and identifies the tab to capture for live transcription. Tab data is used locally only and never transmitted. |
| `contextMenus` | Adds a "Manekilex 查词" item for selected text, used where the bubble cannot appear (Chrome's built-in PDF viewer, the PDF and EPUB readers). |
| `sidePanel` | Shows lookup results in the side panel for Chrome's built-in PDF viewer, where the extension cannot draw on the page. |
| `tabCapture` | Optional live transcription of a tab's audio, started only by the user from the toolbar popup. Audio is streamed to AssemblyAI with the user's own key and not stored. |
| `activeTab` | Lets the toolbar popup start a capture of the current tab after the user clicks the extension icon. |
| Host permissions for `api.openai.com`, `api.deepseek.com`, `api.moonshot.cn`, `open.bigmodel.cn`, `api.siliconflow.cn`, `api.groq.com`, `generativelanguage.googleapis.com` | Sends the user's lookups to the AI provider the user configured with their own API key. Endpoints are fixed in the code. |
| Host permission for `streaming.assemblyai.com` | Live transcription with the user's own AssemblyAI key (temporary token request and WebSocket audio stream). |
| `mime_types_handler` for `application/pdf` | Opens web PDFs in the extension's PDF reader (Chrome 151+) so words can be selected and looked up. The user can switch back to Chrome's viewer or turn this off in settings. |

`activeTab` 是否必需尚未用实验确认（工具栏弹窗里的 `tabCapture.getMediaStreamId` 调用流程依赖用户点击扩展图标）。提交前可以去掉它再验证一次标签页捕获，能去掉就去掉。

## 6. 远程代码

选择「否，我没有使用远程代码」。依据：所有 JavaScript 和 WebAssembly 都随扩展打包（`lib/` 为固定版本、与 npm 官方包逐字节一致）；扩展页面 CSP 为 `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`；不加载远程脚本，不使用 `eval`；模型返回的是 JSON 数据，只当作文本显示。

## 7. 数据使用披露（隐私标签页勾选项）

「收集」按官方说明包括发送出设备的数据。建议如下，最终由维护者确认：

| 类别 | 建议 | 依据 |
| --- | --- | --- |
| 身份验证信息 | 勾选 | 用户自己的 API Key 保存在本机，并作为认证发给对应服务商 |
| 网站内容 | 勾选 | 选中的文字和所在句子发给用户配置的模型服务商 |
| 个人通讯 | 维护者决定（建议勾选） | 实时转译可能捕获通话或会议的标签页音频并发给 AssemblyAI |
| 网络浏览记录 | 维护者决定 | 生词本在本机记录查词所在网页的地址和标题，不发出设备 |
| 个人身份信息、健康、财务、位置、用户活动 | 不勾选 | 代码中没有收集 |

需要声明的三项：不出售或转让给第三方（用途范围内的服务商除外）；不用于与单一用途无关的目的；不用于信用评估或借贷。按代码，这三项都可以如实声明。
